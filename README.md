# Portfoliotur

Independent multilingual portfolio for Oscar Gonzalez Tur.

## Stack

- React
- TypeScript
- Vite
- Custom CSS

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The Vite base path is configured for `https://krontur.github.io/portfolio-tur/`.
The repository is `Krontur/portfolio-tur`, with GitHub Pages set to use GitHub Actions.
